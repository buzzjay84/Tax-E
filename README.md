# Tax-E

Releases of **Tax-E** — personnel withholding tax, benefits classification and tax reconciliation for DepEd personnel.

Download the latest installer from [Releases](../../releases/latest):

- **Windows:** `tax-e-setup-<version>.exe`
- **macOS:** `tax-e-<version>-arm64.dmg` (Apple Silicon) or `tax-e-<version>-x64.dmg` (Intel). The app is not signed with an Apple certificate: the first time, right-click the app and choose **Open**.

The source code is private. This repository only builds and publishes the installers.
